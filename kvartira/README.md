# Студия у Байтерека — лендинг

Одностраничный сайт квартиры посуточно для бренда «Ключи 24» из
[`zaselenie/`](../zaselenie/). Сделан по приёму из ролика
«NanoBanano → Kling → Claude Code»: на первом экране зациклен видео-фон,
дальше 10-секундный проезд камеры через комнату «день → ночь» проигрывается в такт прокрутке.

Открывается без сборки: `kvartira/index.html`.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html` | семь секций: hero, скролл-анимация, квартира, цены, заселение, правила, бронь |
| `css/style.css` | палитра из кадров (беж, дуб, янтарь, сумерки), адаптив, `prefers-reduced-motion` |
| `js/main.js` | рисует кадры на `canvas` по прогрессу прокрутки, появление блоков, шапка |
| `media/hero-loop.mp4` | зацикленный фон первого экрана, 1280×720, 5 с, без звука |
| `media/frames/0001…0160.jpg` | кадры проезда для скролл-анимации |
| `media/day.jpg`, `media/night.jpg` | постер видео и фон блока брони |

Цены, правила и контакты взяты из `zaselenie/js/knowledge.js`
(объект `studio-baiterek`). Ссылка на бота — `https://t.me/kluchi24_bot`,
замените на реальную в `index.html`.

## Как сделаны видео

1. Два кадра в Nano Banana 2.1 (2K, 16:9): дневной интерьер от входа и
   ночной кадр у окна с опорой на первый, чтобы комната совпала.
2. Два ролика в Kling 3.0 (pro, без звука): луп 5 с «кадр → тот же кадр»
   с движением занавесок и проезд 10 с от дневного кадра к ночному.
3. Из проезда нарезано 160 кадров:
   `ffmpeg -i dolly.mp4 -vf "fps=160/10.04,scale=1280:720" -q:v 5 frames/%04d.jpg`

Чтобы заменить анимацию, положите новые кадры в `media/frames/` и поправьте
`FRAMES` в `js/main.js`.
