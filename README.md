# 212

## Приложение для учёта займов

Папка [`credit/`](credit/) — мобильное приложение (PWA) для учёта займов под проценты: клиенты, суммы, даты, автоматический расчёт процентов и просрочки. Инструкция по установке на iPhone — в [credit/README.md](credit/README.md).

## Приложение для учёта автопарка

Папка [`fleet/`](fleet/) — мобильное приложение (PWA) для спецтехники и ГСМ:
заправки, норма расхода против факта, график уровня топлива в баке, недостача по
замерам, фиксация сливов, путевые листы с наработкой, склад топлива, регламент
обслуживания и себестоимость моточаса. Загружает выгрузки из телематики (Wialon,
Omnicomm, заводские системы). Инструкция и описание расчётов —
в [fleet/README.md](fleet/README.md).

## Конвейер фриланс-заказов

Папка [`freelance-pipeline/`](freelance-pipeline/) — система на Node.js, которая
собирает заказы из легальных источников, оценивает их через Claude, ранжирует по
ожидаемой прибыли за час, присылает лучшие в Telegram и готовит отклики. Ведёт
журнал проектов, времени и денег. Запуск и устройство — в
[freelance-pipeline/README.md](freelance-pipeline/README.md).
