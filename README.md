## Приложение для учёта займов

Папка [`credit/`](credit/) — мобильное приложение (PWA) для учёта займов под проценты: клиенты, суммы, даты, автоматический расчёт процентов и просрочки. Инструкция по установке на iPhone — в [credit/README.md](credit/README.md).

## CHAZOR AI

Папка [`chazor-ai/`](chazor-ai/) — прототип iOS-приложения CHAZOR AI: AI-компаньон для BYD Chazor с поездками, батареей, расходом, обслуживанием, диагностикой и ассистентом Claude, плюс интерфейс Apple CarPlay на официальных шаблонах. Swift 5 / SwiftUI / SwiftData, архитектура подготовлена под реальные данные автомобиля через Bluetooth OBD-II и CAN (только чтение).

Экраны можно посмотреть без Xcode: [`chazor-ai/preview/`](chazor-ai/preview/). Подробности — в [chazor-ai/README.md](chazor-ai/README.md).
