# 212

## Приложение для учёта займов

Папка [`credit/`](credit/) — мобильное приложение (PWA) для учёта займов под проценты: клиенты, суммы, даты, автоматический расчёт процентов и просрочки. Инструкция по установке на iPhone — в [credit/README.md](credit/README.md).

## Сайт-меню для заведений

Папка [`menu/`](menu/) — продукт на продажу: сайт-меню, которое принимает
заказ и отправляет его готовым текстом в WhatsApp или Telegram заведения.
Без сервера и без комиссий агрегаторов. Подробности — в [menu/README.md](menu/README.md).

Папка [`sales/`](sales/) — коммерческая часть: оффер и цены, скрипты продаж,
база из 32 заведений Ташкента, персональные сообщения и финансовый дашборд.
См. [sales/README.md](sales/README.md).
