## QORA — студия сайтов для заведений (Ташкент)

Действующий мини-бизнес: сайт для кафе или ресторана за 24 часа, приём заказов напрямую в мессенджер владельца без комиссии агрегаторов.

Операционные расходы — 0 сум: сайты статические, приём заказов идёт deep-link'ом в мессенджер, сервер и хостинг не нужны.

### Движок

```bash
cp engine/clients/kunduz.json engine/clients/новый-клиент.json   # отредактировать
node engine/build.js                                             # → demo/новый-клиент/index.html
```

Один JSON — один готовый сайт: меню, корзина, заказ в WhatsApp/Telegram, разметка для поиска, QR-меню. Ни одного секрета в собранном файле.
