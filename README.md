# 212

## Приложение для учёта займов

Папка [`credit/`](credit/) — мобильное приложение (PWA) для учёта займов под проценты: клиенты, суммы, даты, автоматический расчёт процентов и просрочки. Инструкция по установке на iPhone — в [credit/README.md](credit/README.md).

## Приложение для учёта топлива

Папка [`fuel/`](fuel/) — мобильное приложение (PWA) для учёта заправок техники: расход против нормы, остаток в своей бочке, недостачи и ТО по наработке. Работает офлайн, данные хранятся на телефоне. Подробности — в [fuel/README.md](fuel/README.md).
