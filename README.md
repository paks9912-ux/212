# 212

## Приложение для учёта займов

Папка [`credit/`](credit/) — мобильное приложение (PWA) для учёта займов под проценты: клиенты, суммы, даты, автоматический расчёт процентов и просрочки. Инструкция по установке на iPhone — в [credit/README.md](credit/README.md).

## AI-агент для заселения гостей

Папка [`zaselenie/`](zaselenie/) — агент, который принимает заявки на посуточное
заселение: разбирает сообщение гостя, считает цену по календарю и тарифам,
отвечает по сценариям и доводит заявку до брони. Демо, база знаний, промпты
и тесты — в [zaselenie/README.md](zaselenie/README.md).
