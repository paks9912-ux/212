# Сайт СУ №4 — концепт редизайна

Статический сайт: обычные HTML, CSS и один скрипт. Ни сборки, ни зависимостей,
ни базы данных — можно положить на любой хостинг и открыть.

## Как выложить

Скопируйте содержимое этой папки в корень сайта. Точка входа — `index.html`.
Работает и локально: откройте `index.html` двойным щелчком.

## Что где лежит

    index.html                  главная: направления, все объекты, контакты
    services/<направление>/     шесть страниц направлений
    projects/djamgyr/           кейс объекта
    assets/site.css             все стили
    assets/site.js              весь скрипт (~5 КБ)
    assets/img/                 фотографии
    assets/video/               фоновое видео первого экрана
    assets/logo*.png            логотип: оригинал и выворотка для тёмного фона
    data/site.js                содержание услуг и объектов
    tools/build-pages.js        сборка страниц из data/site.js
    tools/build-standalone.js   сборка одной страницы в один файл (для предпросмотра)

## Как менять содержание

Тексты, параметры и списки объектов — в `data/site.js`. После правки:

    node tools/build-pages.js

Шесть страниц направлений пересоберутся. Главная и кейс правятся напрямую.

## Глубина

Сайт двухуровневый: с главной один клик до любой страницы, «Назад» в шапке
возвращает в нужный раздел главной. Отдельных списков услуг и проектов нет —
их роль выполняют разделы главной, иначе появлялся лишний уровень вложенности.

## Что нужно доделать перед запуском

- Год, локация и объёмы по каждому объекту в `data/site.js` — сейчас стоит «—».
- Реквизиты, номера лицензий и сертификатов для страницы о компании.
- Текст политики обработки персональных данных (ссылка в форме ждёт страницу).
- Подключить форму к почте или CRM: сейчас она показывает подтверждение, но
  никуда не отправляет.
- Заменить видео первого экрана на съёмку собственного цеха.
- Проверить адрес почты в форме: `info@su4.kg` поставлен как предположение.
