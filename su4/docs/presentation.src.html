02 / Текущий сайт

Компания сильнее, чем её цифровое представительство.

На сайте есть практически вся нужная информация: услуги, производство, проекты, история, партнёры, контакты. Дело не в количестве информации.

Вопрос в другом: насколько быстро новый посетитель соберёт из неё целостное представление о компании.

14 / Интерфейс в движении

Современный интерфейс — это не эффект ради эффекта.

Запись работы сайта: первый экран, каталог направлений, фильтр объектов, просмотр фотографии, форма заявки. Движение помогает понять интерфейс, а не украшает его.
