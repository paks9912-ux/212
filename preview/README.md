# preview/ — черновик KYOTO 2.0

**Действующий сайт — `/index.html` в корне. Он не изменён.**
Этот каталог существует только для просмотра и согласования.

## Как посмотреть

Скачайте `preview/index.html` и откройте двойным кликом в браузере.
Файл самодостаточный: ни сборки, ни сервера, ни зависимостей.
Фотографии подгружаются с Unsplash — как и на действующем сайте.

## Важно перед выкаткой

В `<head>` стоит `<meta name="robots" content="noindex, nofollow">`,
чтобы черновик не попал в поиск. **При переносе в прод его нужно снять.**

## Реальные данные

Всё, что зависит от фактов, вынесено в объект `SITE` в начале `<script>`.
Пустое значение = блок не показывается. Ни одна цифра не выдумана.
