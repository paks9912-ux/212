# Сайт-меню с прямыми заказами

Одностраничный сайт заведения: гость собирает заказ, а заведению приходит
**готовый текст заказа в WhatsApp или Telegram** — состав, адрес, сумма.

Без сервера, без базы данных, без админки. Готовый сайт — **один HTML-файл**,
который работает на любом статическом хостинге (GitHub Pages, Netlify) или
даже с флешки. Комиссии с заказов нет.

## Что умеет

- Меню по категориям с закреплённой панелью навигации
- Корзина, которая переживает перезагрузку страницы
- Доставка и самовывоз; при самовывозе доставка не считается
- Минимальная сумма заказа — оформление блокируется ниже порога
- Порог бесплатной доставки с индикатором «сколько осталось добрать»
- Оформление: имя, телефон, адрес, время, способ оплаты, комментарий
- Проверка полей — заказ без телефона или адреса не уйдёт
- Отправка в WhatsApp (ссылка с готовым текстом), в Telegram (текст
  копируется в буфер и открывается чат), звонок
- Тёмная и светлая тема, часы работы, старая цена, метки «ХИТ»
- Демо-режим (`"demo": true`) — вместо перехода в мессенджер показывает
  сам текст заказа. Для показа потенциальным клиентам.

## Как собрать сайт

**Через конструктор (быстро, без кода):** открыть `builder.html`, заполнить
данные, вставить меню текстом, нажать «Скачать готовый сайт».

**Из файла (для повторяемости):**

```bash
node menu/tools/build-site.js               # все shops/*.json, кроме lead-*
node menu/tools/build-site.js shops/x.json  # конкретное заведение
```

Результат — `menu/dist/<id>.html`.

## Формат заведения

```jsonc
{
  "name": "SAKURA",
  "whatsapp": "998901234567",        // куда падают заказы
  "telegram": "sakura_uz",
  "currency": "сум",
  "hours":    { "from": "10:00", "to": "23:00" },
  "delivery": { "fee": 15000, "freeFrom": 200000, "minOrder": 80000,
                "time": "40–60 мин", "zone": "Ташкент" },
  "payments": ["Наличными курьеру", "Click / Payme"],
  "categories": [
    { "name": "Роллы",
      "items": [ { "name": "Филадельфия", "desc": "лосось, сыр",
                   "weight": "260 г", "price": 68000, "tag": "ХИТ" } ] }
  ]
}
```

`id` у позиций проставляется автоматически — и при сборке, и в самом движке.

## Разбор чужого меню

`tools/parse-menu.js` понимает меню, скопированное из Instagram, Excel или
переписки:

```
Роллы:
Филадельфия — 68 000
Дракон | угорь, огурец | 270 г | 79000
Кола 0,5 12000
```

## Тесты

```bash
node menu/tests/e2e.js            # заказ в реальном браузере, 26 проверок
node menu/tests/builder.test.js   # конструктор и собранный им файл
```

`e2e.js` прогоняет денежный путь целиком: добавление в корзину, пороги
доставки, минимальную сумму, валидацию формы и текст заказа, который
получит заведение.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → ветка, папка `/ (root)`.
Через минуту: `https://<логин>.github.io/212/menu/dist/<id>.html`
