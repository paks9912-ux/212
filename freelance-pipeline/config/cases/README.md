# Библиотека кейсов

Каждый кейс — отдельный файл `.md` в этой папке. Из них собираются отклики:
модель подбирает 1–2 самых похожих и ссылается на них. Без кейсов отклик
получается общим и проигрывает.

Шаблон:

```
---
title: Лендинг для стоматологии
services: [landing, mobile]
url: https://example.com
budget_usd: 450
hours: 5.5
year: 2026
---
Что было: клиент прислал референс и три абзаца текста.
Что сделал: одностраничник на HTML/CSS/JS, форма записи в Telegram,
адаптив под телефон, скорость 98/100.
Результат: сдал за два дня, клиент вернулся с сайтом клиники.
```
