# Шаблон лендинга

Одностраничник без фреймворков и внешних шрифтов: три файла, грузится за
секунду, проходит `npm run qa` без замечаний. Под новый заказ меняются тексты,
цвета в `:root` и адрес формы.

Что внутри: шапка с меню на телефоне, герой с фактами, услуги с ценами, шаги,
таблица цен, вопросы-ответы на `<details>`, контакты и форма с проверкой
полей, ловушкой для ботов и отправкой JSON на любой вебхук.

## Под клиента

1. Скопируйте папку: `cp -r templates/landing ~/clients/<имя>`.
2. Тексты — в `index.html`, цвета и радиусы — в `:root` в `style.css`.
3. Форма: в `<form data-endpoint="">` укажите вебхук n8n или другой обработчик.
   Приходит JSON `{name, phone, message, page, at}`. Пустой адрес форма
   честно показывает как ошибку, QA-скрипт это ловит.
4. Картинки: замените SVG-заглушку в герое на `<img src="hero.webp" alt="…"
   width="960" height="720" loading="eager">`. Остальные — `loading="lazy"`.
5. Проверка: `npm run qa -- ~/clients/<имя>`.

Сдавать: папку целиком, ссылку на хостинг, адрес вебхука и эту инструкцию
клиенту в двух строках.
